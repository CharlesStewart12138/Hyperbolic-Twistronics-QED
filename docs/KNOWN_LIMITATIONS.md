# Known limitations

- This distribution contains current source and runtime configuration, not numerical results or large frozen registries.
- Some tests require products generated by earlier pipeline stages and will report missing inputs in a pristine checkout.
- Exact global registry generation may require substantial disk, memory, and wall time.
- GAP jobs require GAP and the packages named by the individual scripts.
- Native exact-search programs require a C++20 compiler and, where stated, GMP/MPFR.
- There are no Node.js sources; the public workbook builder uses Python/openpyxl.
- The project owner must select an open-source license and citation author list before publication.
