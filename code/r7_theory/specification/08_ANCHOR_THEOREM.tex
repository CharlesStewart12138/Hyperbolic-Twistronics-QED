\section{Frozen hyperbolic anchor}
\label{sec:r7-anchor}

\begin{theorem}[Hyperbolic full-kernel operational anchor]
\label{thm:r7-anchor}
In the frozen centred regular-octagon scalar Hamiltonian there is a nonempty
open decay-and-coupling parameter class containing a positive simple coupling
$w_H$ for which the following hold simultaneously.
\begin{enumerate}
\item The exponential kernel and its differentiated Hodge kernels are Schur
summable.
\item The first-shell layer-even block at $w_1=t/q_1$ is exactly $E_*I$ and
is isolated by $g_*>0$.
\item The full-kernel root $w_H>0$ is unique in the certified interval, has a
nonzero derivative margin, and the full even block satisfies
\eqref{eq:r7-anchor-norm} with $\varepsilon_A<g_*/6$.
\item The target Riesz projector is stable, has active microscopic overlap,
and lies in the exact layer-even sector.
\item Regular-octagon symmetry forces the full Hodge response to be
$\mathcal K(w)=2tC_S-wb_\infty C_S$; therefore
$w_H=2t/b_\infty$ cancels every canonical Hodge component, with common
nonzero slope.
\end{enumerate}
For every resolution satisfying \eqref{eq:r7-anchor-resolution}, the exact
infinite operator $H(0,p_A)$ has the strict certificate
\eqref{eq:r7-anchor-five} and $\Delta_{\rm magic}\ge1/48$.
\end{theorem}

\begin{proof}
Items 1--5 are the frozen READY/REVISED scalar theorems: weighted Schur
continuation, the regular-representation parity identity, Weyl/Riesz
stability, and the regular-octagon Gram-commutant theorem.  Their conjunction
gives \eqref{eq:r7-anchor-norm}; Proposition~\ref{prop:r7-anchor-margin}
then proves the five operational inequalities.  Openness follows because
the root slope, gap, Riesz-contour distance, and strict inequalities are all
positive and norm-continuous.  No finite-cover convergence or KPM peak is
used.
\end{proof}

The theorem does not claim that every curvature or every Hamiltonian is
magic.  It supplies an explicit nonempty parameter class in the frozen scalar
family.  The unfrozen three-orbital parameterization is not used.
